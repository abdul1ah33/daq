Try each exercise yourself first. If you get stuck, open the hints one at a time, and only then look at the solution.

Quick recap from the lecture

  • input("prompt") shows a prompt and returns what the user typed, always as a string. print() can take several values separated by commas.
  • Files: f = open(filename, mode) with mode 'r' (read), 'w' (write) or 'b' (binary). Read with f.read(), f.readline(), f.readlines() or for line in f:. Write with f.write(string). Finish with f.close().
  • if / elif / else: the first true condition wins and else is optional. Python has no switch; you use if/elif chains instead.
  • Falsy values: None, False, 0, 0.0, '' and empty data structures. Everything else is truthy.
  • Check for an empty list with if data:. You should almost never write if expr == True.

7.9Fix the bug
Fix the knights program
Change the program so a knight with no fights prints Mordred: no fights yet instead of crashing.
File: knights.txt
Lancelot 6 0
Galahad 7 12
Geraint 3 1
Mordred 0 0
Buggy code
f = open("knights.txt")
for line in f:
    data = line.split(' ')
    name = data[0]
    wins = int(data[1])
    losses = int(data[2])
    win_percent = 100 * wins / (wins + losses)
    print("%s: Wins %.2f" % (name, win_percent))
f.close()
  1. Step 1. Compute the total number of fights first: total = wins + losses.
  2. Step 2. Use if total == 0: to handle the special case before you divide.
  3. Step 3. Put the percentage calculation and its print in the else: branch.
Show the full solution
Solution
f = open("knights.txt")
for line in f:
    data = line.split(' ')
    name = data[0]
    wins = int(data[1])
    losses = int(data[2])
    total = wins + losses
    if total == 0:
        print(name + ": no fights yet")
    else:
        win_percent = 100 * wins / total
        print("%s: Wins %.2f" % (name, win_percent))
f.close()
Expected output

Galahad: Wins 36.84

7.10Write code
Write a file, then read it back
Write three lines (red, green, blue) to colors.txt. Then open it again, read all lines with readlines(), and print the list and how many lines there are.
  1. Step 1. Open for writing with f = open("colors.txt", "w").
  2. Step 2. f.write() does not add a newline for you, so write "red\n" and so on.
  3. Step 3. Always call f.close() when you are done writing, before reading the file again.
  4. Step 4. Re-open with mode "r" (or no mode), then lines = f.readlines().
Show the full solution
Solution
f = open("colors.txt", "w")
f.write("red\n")
f.write("green\n")
f.write("blue\n")
f.close()

f = open("colors.txt", "r")
lines = f.readlines()
f.close()
print(lines)
print(len(lines))
Expected output
['red\n', 'green\n', 'blue\n']
3
readlines() keeps the \n at the end of each line. Use line.strip() if you want to remove it.
