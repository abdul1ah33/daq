Week 4 · Games & Adversarial Search

Try each exercise yourself first. If you get stuck, open the hints one at a time, and only then look at the solution.

Quick recap from the lecture

  • Games: two players (MAX, MIN), alternating turns, zero-sum, perfect information. The solution is a strategy.
  • Formal parts: initial state, Player(s), Actions(s), Result(s,a), Terminal-Test(s), Utility(s,p).
  • Minimax: MAX takes the max of its children, MIN the min. Complete (finite), optimal vs. optimal opponent, O(bm) time, O(bm) space.
  • Too big to search fully (chess ≈ 10154): cut off and use an evaluation function, e.g. tic-tac-toe E(n) = M(n) − O(n).
  • Alpha-beta: α = best for MAX, β = best for MIN on the path; prune when α ≥ β. Same result as minimax; best case O(bd/2).

4.4Write code

Code minimax

Write a recursive minimax(node, is_max) where leaves are numbers and inner nodes are lists. Print the root value and the MIN values of the classic tree.
Starter code
tree = [[3, 12, 8], [2, 4, 6], [14, 5, 2]]
  1. Step 1. Base case: if not isinstance(node, list): return node.
  2. Step 2. Recursive case: values = [minimax(c, not is_max) for c in node].
  3. Step 3. return max(values) if is_max else min(values).
Show the full solution
Solution
tree = [[3, 12, 8], [2, 4, 6], [14, 5, 2]]

def minimax(node, is_max):
    if not isinstance(node, list):
        return node
    values = [minimax(c, not is_max) for c in node]
    return max(values) if is_max else min(values)

print("root:", minimax(tree, True))
print("MIN nodes:", [minimax(c, False) for c in tree])
Expected output
root: 3
MIN nodes: [3, 2, 2]

4.5Write code
Code alpha-beta and list the pruned leaves
Extend minimax with α and β. Record every leaf you actually evaluate in a list, so you can see which ones were skipped.
Starter code
tree = [[3, 12, 8], [2, 4, 6], [14, 5, 2]]
seen = []
  1. Step 1. Signature: def ab(node, alpha, beta, is_max):. For a leaf: append it to seen and return it.
  2. Step 2. MAX: v = -inf; for each child v = max(v, ab(c, alpha, beta, False)); if v >= beta: return v; alpha = max(alpha, v).
  3. Step 3. MIN is the mirror: v = +inf, min, return if v <= alpha, update beta.
  4. Step 4. Use float("inf") for infinity.
Show the full solution
Solution
tree = [[3, 12, 8], [2, 4, 6], [14, 5, 2]]
seen = []
INF = float("inf")

def ab(node, alpha, beta, is_max):
    if not isinstance(node, list):
        seen.append(node)
        return node
    if is_max:
        v = -INF
        for c in node:
            v = max(v, ab(c, alpha, beta, False))
            if v >= beta:
                return v
            alpha = max(alpha, v)
    else:
        v = INF
        for c in node:
            v = min(v, ab(c, alpha, beta, True))
            if v <= alpha:
                return v
            beta = min(beta, v)
    return v

print("root:", ab(tree, -INF, INF, True))
print("evaluated leaves:", seen)
Expected output
root: 3
evaluated leaves: [3, 12, 8, 2, 14, 5, 2]
7 of the 9 leaves are evaluated: 4 and 6 are skipped, exactly as on the slides.

Tic-tac-toe evaluation E(n)
This program counts open lines for X and O. What does it print?
Code
lines = [(0,1,2),(3,4,5),(6,7,8),(0,3,6),(1,4,7),(2,5,8),(0,4,8),(2,4,6)]

def E(board):
    m = sum(1 for l in lines if all(board[i] != "O" for i in l))
    o = sum(1 for l in lines if all(board[i] != "X" for i in l))
    return m, o, m - o

print(E("O   X    "))
print(E("X   O    "))
print(E(" X  O    "))

  2. Step 2. X centre, O corner: X loses the 3 corner lines → 5; O loses the 4 centre lines → 4.
  3. Step 3. X corner, O centre → 4 and 5. X edge, O centre → 4 and 6.
