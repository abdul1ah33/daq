Loops

Try each exercise yourself first. If you get stuck, open the hints one at a time, and only then look at the solution.

Quick recap from the lecture

  • for item in sequence: loops directly over a string, list, tuple, set or dict. You do not need an index counter like in Java.
  • print(x, end='|') changes what comes after each print. The default is a newline.
  • zip(a, b) gives pairs from two sequences, and for k, v in d.items(): loops over a dictionary.
  • range(stop) or range(start, stop[, step]) counts from start up to but not including stop.
  • break leaves the innermost loop immediately. continue skips to the next iteration.
  • while condition: repeats as long as the condition is true. enumerate() gives the index and the item together, so you should almost never need for i in range(len(seq)).

Countdown
Use a while loop to print 5, 4, 3, 2, 1 on separate lines and then Go!.
  1. Step 1. Start with count = 5.
  2. Step 2. Loop while count > 0.
  3. Step 3. Inside: print the count, then reduce it with count -= 1. If you forget this, the loop never ends.
  4. Step 4. Print Go! after the loop, with no indentation.
Show the full solution
Solution
count = 5
while count > 0:
    print(count)
    count -= 1
print("Go!")

8.11Write code
Fibonacci (lecture exercise)
Write fib(n) that prints the first n Fibonacci numbers, each with its position, then call fib(8).
  1. Step 1. Start with the first two numbers: a, b = 0, 1.
  2. Step 2. Loop n times with for i in range(n):.
  3. Step 3. Print i, a, then move forward one step: the new a is the old b, and the new b is a + b.
  4. Step 4. Use tuple packing so both update at the same moment: a, b = b, a + b.
Show the full solution
Solution
def fib(n):
    """Prints the first n Fibonacci numbers."""
    a, b = 0, 1
    for i in range(n):
        print(i, a)
        a, b = b, a + b

fib(8)
Expected output
0 0
1 1
2 1
3 2
4 3
5 5
6 8
7 13
Why tuple packing matters: if you wrote a = b and then b = a + b, the second line would use the new a, and the sequence would come out wrong.
