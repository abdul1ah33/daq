Quick recap from the lecture

  • AI = reproducing human reasoning and intelligent behaviour by computational methods. Four approaches: think like humans · act like humans · think rationally · act rationally.
  • Rational approach: always make the best decision given knowledge, time and resources, i.e. maximize expected utility.
  • Turing test (1950): an interrogator questions it with no physical interaction; it passes if they can't tell it from a person. CAPTCHA reverses it.
  • Agent: f: P* → A (percept histories → actions). Agent = Architecture + Program. Specify tasks with PEAS.
  • Environment types: observable, deterministic, episodic, static, discrete, single-agent (and their opposites).
  • Agent types (taxi example): simple reflex → keeps track of the world (internal state) → goal-based (search & planning) → utility-based (utility function).

1.5Write code

A simple reflex vacuum agent

Write reflex_vacuum(location, status) for the two-square world: Suck if the square is Dirty, else move Right from A and Left from B. Test it on the four possible percepts.
  1. Step 1. The percept is a pair like ("A", "Dirty").
  2. Step 2. Check the status first: if status == "Dirty": return "Suck".
  3. Step 3. Then elif location == "A": return "Right", else: return "Left".
Show the full solution
Solution
def reflex_vacuum(location, status):
    if status == "Dirty":
        return "Suck"
    elif location == "A":
        return "Right"
    else:
        return "Left"

for percept in [("A", "Dirty"), ("A", "Clean"), ("B", "Dirty"), ("B", "Clean")]:
    print(percept, "->", reflex_vacuum(*percept))
Expected output
('A', 'Dirty') -> Suck
('A', 'Clean') -> Right
('B', 'Dirty') -> Suck
('B', 'Clean') -> Left

*percept unpacks the tuple into the two arguments. This agent is a pure condition → action table: a simple reflex agent.
