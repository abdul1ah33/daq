Q1Interpreter & comments
>>> word = "hi"
>>> word * 2

What does the interactive interpreter show after the second line?

  • Hint. The interpreter echoes the value of an expression the same way it would appear in code.
  1. Line 1 is an assignment, so nothing is echoed.
  2. word * 2 repeats the string, giving hihi.
  3. Because it is a string value and not a print, the interpreter shows it with quotes: 'hihi'.
Q2Interpreter & comments
x = 1  # x = 2
"""
x = 3
"""
print(x)  # print(x + 1)

What is printed?

  • Hint. Cross out everything that is a comment or inside the triple quotes.
  1. x = 1 runs. The # x = 2 part is a comment.
  2. x = 3 is inside a triple-quoted string, so it is only text and does not run.
  3. print(x) runs and prints 1. The rest of that line is a comment.
Q3Variables & types

What is printed?

  • Hint. After line 2, x is 7. What does str(7) give, and what does + do with two strings?
  1. x = 5, then x = 5 + 2 = 7.
  2. str(7) is the text "7", and "7" + "5" joins them into "75".
  3. print shows strings without quotes, so the output is 75.

Q7Numbers & booleans
print(17 // 5, 17 % 5, 2 ** 3)

What is printed?

  • Hint. // counts whole groups, % gives what is left over, ** is the power.
  1. 5 goes into 17 three whole times, so 17 // 5 = 3.
  2. 3 × 5 = 15, and 17 − 15 leaves 2, so 17 % 5 = 2.
  3. 2 ** 3 = 2 × 2 × 2 = 8.
Q8Numbers & booleans

What is printed?

  • Hint. // rounds down (toward minus infinity), not toward zero.
  1. −7 / 2 = −3.5.
  2. Rounding −3.5 down gives −4 (−4 is smaller than −3.5).
Q9Numbers & booleans
print(1 < 2 >= 3, 1 < 2 < 3)

What is printed?

  • Hint. Split each chain into pairs joined with and.
  1. 1 < 2 >= 3 means 1 < 2 and 2 >= 3, which is True and False, so False.
  2. 1 < 2 < 3 means 1 < 2 and 2 < 3, which is True and True, so True.
Q10Numbers & booleans

What is printed?

  • Hint. bool is a subtype of int.
  1. True behaves like 1 and False behaves like 0.
  2. 1 + 1 + 0 = 2.
Q11Numbers & booleans

What is printed?

  • Hint. / and * have the same priority, so work from left to right.
  1. 10 / 4 = 2.5 (a float).
  2. 2.5 * 2 = 5.0. It stays a float.
Q12Numbers & booleans

What is printed?

  • Hint. Work from the inside of the parentheses outwards.
  1. 3 > 2 is True and 2 > 5 is False, so True and False is False.
  2. not False is True.
  3. True or False is True.

Q47Control flow & I/O
File: knights.txt
Lancelot 6 0
Galahad 7 12
Geraint 3 1
Mordred 0 0
f = open("knights.txt")
for line in f:
    data = line.split(' ')
    name = data[0]
    wins = int(data[1])
    losses = int(data[2])
    win_percent = 100 * wins / (wins + losses)
    print("%s: Wins %.2f" % (name, win_percent))
f.close()

knights.txt holds the four lines from the lecture (Lancelot 6 0, Galahad 7 12, Geraint 3 1, Mordred 0 0). What is the output?

  • Hint. Look closely at Mordred's line: Mordred 0 0.
  1. Lancelot: 100 × 6 / 6 = 100.00.
  2. Galahad: 100 × 7 / 19 ≈ 36.84.
  3. Geraint: 100 × 3 / 4 = 75.00.
  4. Mordred: wins + losses = 0, and dividing by 0 raises ZeroDivisionError.
