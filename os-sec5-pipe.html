Lab Section 5 · pipe()

Try each exercise yourself first. If you get stuck, open the hints one at a time, and only then look at the solution.

Quick recap from the lecture

  • A pipe lets related processes communicate (IPC). It is one-way: fds[1] is the write end, fds[0] the read end. pipe() returns 0, or −1 on error.
  • Create the pipe before fork() so the child inherits both ends; each process closes the end it doesn't use.
  • Data comes out in the order it went in. A full pipe blocks the writer; an empty pipe blocks the reader. So the pipe synchronizes the processes.
  • write(fd, buf, n) returns bytes written or −1; read(fd, buf, n) returns bytes read, −1 on error, 0 at EOF (all write ends closed, no data left).
  • Two-way communication needs two pipes.
  • Compile and run in a Linux terminal: gcc file.c -o prog then ./prog. These are C programs, so there is no in-browser editor; the outputs shown come from real runs.

7.1Think & answer

Which ends to close?

The child sends a message to the parent. Which descriptors should each process close, and why does it matter for a while(read(...) > 0) loop?
  1. Step 1. The writer doesn't read; the reader doesn't write.
  2. Step 2. When does read() return 0?
Show the answer
Answer

Child (writer): close fds[0]; close fds[1] when finished writing. Parent (reader): close fds[1]; close fds[0] when done.

read() returns 0 only when every write end is closed. If the reader forgets to close its own copy of fds[1], its read loop never ends.

7.3Write code

Send a number through a pipe

The parent sends the int 21 to the child through a pipe. The child reads it and prints “child received 21, doubled = 42”.
  1. Step 1. Call pipe(fds) before fork().
  2. Step 2. Parent: write(fds[1], &value, sizeof(int)); (as Example 1 sends size).
  3. Step 3. Child: read(fds[0], &x, sizeof(int)); then printf.
Show the full solution
Solution
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>

int main(){
    int fds[2];
    pipe(fds);
    if(fork() == 0){                  // child reads
        close(fds[1]);
        int x;
        read(fds[0], &x, sizeof(int));
        close(fds[0]);
        printf("child received %d, doubled = %d\n", x, x * 2);
        exit(0);
    }
    close(fds[0]);                    // parent writes
    int value = 21;
    write(fds[1], &value, sizeof(int));
    close(fds[1]);
    wait(NULL);
    return 0;
}
Expected output
child received 21, doubled = 42
7.4Write code

Ping–pong with two pipes

The parent sends “ping” to the child; the child prints it and replies “pong”, which the parent prints. Use two pipes.
  1. Step 1. A pipe is one-way, so create two before fork.
  2. Step 2. Parent writes to p2c[1] and reads from c2p[0]; the child does the opposite.
  3. Step 3. The parent's read blocks until the child replies, so the order of the output is fixed.
Show the full solution
Solution
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>

int main(){
    int p2c[2], c2p[2];              // parent->child, child->parent
    char buf[16] = {0};
    pipe(p2c);
    pipe(c2p);
    if(fork() == 0){
        close(p2c[1]); close(c2p[0]);
        read(p2c[0], buf, 4);
        printf("child got: %s\n", buf);
        write(c2p[1], "pong", 4);
        exit(0);
    }
    close(p2c[0]); close(c2p[1]);
    write(p2c[1], "ping", 4);
    read(c2p[0], buf, 4);
    printf("parent got: %s\n", buf);
    wait(NULL);
    return 0;
}
Expected output
child got: ping
parent got: pong
7.5Fix the bug

The read loop never ends

The child should print “Message Received:Hello” and the program should end, but it hangs forever. Find and fix the bug.
Buggy code
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>

int main(){
    int fds[2];
    char buf;
    pipe(fds);
    if(fork() == 0){                  // child reads
        printf("Message Received:");
        while(read(fds[0], &buf, 1) > 0)
            printf("%c", buf);
        printf("\n");
        exit(0);
    }
    close(fds[0]);
    write(fds[1], "Hello", 5);
    close(fds[1]);
    wait(NULL);
    return 0;
}
  1. Step 1. read() returns 0 only when ALL write ends are closed.
  2. Step 2. The parent closes its write end. Does the child?
  3. Step 3. Add close(fds[1]); at the start of the child branch, as Example 2 does.
Show the full solution
Solution
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>

int main(){
    int fds[2];
    char buf;
    pipe(fds);
    if(fork() == 0){                  // child reads
        close(fds[1]);                // close the unused write end!
        printf("Message Received:");
        while(read(fds[0], &buf, 1) > 0)
            printf("%c", buf);
        printf("\n");
        exit(0);
    }
    close(fds[0]);
    write(fds[1], "Hello", 5);
    close(fds[1]);
    wait(NULL);
    return 0;
}
Expected output
Message Received:Hello
