Quick recap from the lecture

  • Neuron mapping: soma → node, dendrites → input, axon → output, synapse → weight. A neuron weights its inputs, sums them and applies a nonlinear function.
  • Perceptron: f(x) = 1 if w·x + b > 0 else 0. Trained with the delta rule. Learns only linearly separable patterns, so it cannot learn XOR.
  • Sigmoid 1/(1+e−x), range [0,1], derivative f(1−f). tanh range [−1,1]. MLPs are feed-forward and fully connected.
  • Backprop: Ij = ΣwijOi + θj; Oj = sigmoid(Ij); output Err = O(1−O)(T−O); hidden Err = O(1−O)ΣErrkwjk; Δw = l·Errj·Oi; Δθ = l·Errj.
  • Watch for overfitting (have 5–10× more samples than weights; use early stopping), vanishing gradients, and explainability (sensitivity analysis).

5.1Write code

A perceptron truth table

Write perceptron(w, b, x) and print the outputs of AND (w = (1, 1), b = −1.5) and OR (w = (1, 1), b = −0.5) for all four inputs.
  1. Step 1. Net = w[0]*x[0] + w[1]*x[1] + b.
  2. Step 2. Return 1 if net > 0, else 0.
  3. Step 3. Loop over [(0, 0), (0, 1), (1, 0), (1, 1)].
Show the full solution
Solution
def perceptron(w, b, x):
    net = w[0] * x[0] + w[1] * x[1] + b
    return 1 if net > 0 else 0

for x in [(0, 0), (0, 1), (1, 0), (1, 1)]:
    print(x, "AND:", perceptron((1, 1), -1.5, x), "OR:", perceptron((1, 1), -0.5, x))
Expected output
(0, 0) AND: 0 OR: 0
(0, 1) AND: 0 OR: 1
(1, 0) AND: 0 OR: 1
(1, 1) AND: 1 OR: 1

5.2Think & answer
Why no perceptron can do XOR
Show that no single straight line separates XOR's outputs. Then describe how a hidden layer fixes this.
  1. Step 1. Plot (0,0) → 0, (1,1) → 0, (0,1) → 1, (1,0) → 1.
  2. Step 2. The 1s are on one diagonal and the 0s on the other.
  3. Step 3. Hidden units: h1 = OR, h2 = AND; output = h1 AND NOT h2.
Show the answer
Answer
The 1s sit at opposite corners (0,1) and (1,0), and the 0s at (0,0) and (1,1). Any line that puts both 1s on one side also puts at least one 0 there, so XOR is not linearly separable.

          
With a hidden layer: h1 = OR(x1, x2), h2 = AND(x1, x2), and Y = h1 AND NOT h2, which is exactly XOR.
5.3Write code
The processing-element example
Compute the weighted sum and the sigmoid output for X = (3, 1, 2) and W = (0.2, 0.4, 0.1). Print both with 2 decimals.
  1. Step 1. import math to get math.exp.
  2. Step 2. Y = sum of x × w (use zip).
  3. Step 3. YT = 1 / (1 + math.exp(-Y)).
Show the full solution
Solution
import math
X = (3, 1, 2)
W = (0.2, 0.4, 0.1)
Y = 0
for x, w in zip(X, W):
    Y += x * w
YT = 1 / (1 + math.exp(-Y))
print("Y  = %.2f" % Y)
print("YT = %.2f" % YT)
Expected output
Y  = 1.20
YT = 0.77

import math
x = {1: 1, 2: 0, 3: 1}
w = {(1, 4): 0.2, (1, 5): -0.3, (2, 4): 0.4, (2, 5): 0.1,
     (3, 4): -0.5, (3, 5): 0.2, (4, 6): -0.3, (5, 6): -0.2}

  3. Step 3. Updates: new_w[(i, j)] = w[(i, j)] + l * err[j] * O[i]; theta[j] + l * err[j].

Solution
import math
x = {1: 1, 2: 0, 3: 1}
w = {(1, 4): 0.2, (1, 5): -0.3, (2, 4): 0.4, (2, 5): 0.1,
     (3, 4): -0.5, (3, 5): 0.2, (4, 6): -0.3, (5, 6): -0.2}
theta = {4: -0.4, 5: 0.2, 6: 0.1}
T, l = 1, 0.9
sig = lambda v: 1 / (1 + math.exp(-v))

O = dict(x)
for j in (4, 5):
    I = sum(w[(i, j)] * O[i] for i in (1, 2, 3)) + theta[j]
    O[j] = sig(I)
O[6] = sig(w[(4, 6)] * O[4] + w[(5, 6)] * O[5] + theta[6])

err = {6: O[6] * (1 - O[6]) * (T - O[6])}
for j in (4, 5):
    err[j] = O[j] * (1 - O[j]) * err[6] * w[(j, 6)]

new_w = {k: v + l * err[k[1]] * O[k[0]] for k, v in w.items()}
new_theta = {j: theta[j] + l * err[j] for j in theta}

print("O4 %.4f  O5 %.4f  O6 %.4f" % (O[4], O[5], O[6]))
print("Err6 %.4f  Err5 %.4f  Err4 %.4f" % (err[6], err[5], err[4]))
print("w46 %.4f  w56 %.4f  w14 %.4f" % (new_w[(4, 6)], new_w[(5, 6)], new_w[(1, 4)]))
print("theta6 %.4f" % new_theta[6])

The vanishing gradient
The sigmoid derivative is at most 0.25. What does this print?
Code
g = 1.0
for layer in range(1, 6):
    g *= 0.25
    print(layer, g)
Your prediction
  1. Step 1. Each layer multiplies by 0.25.
  2. Step 2. 0.25, 0.0625, 0.015625, …
Show the answer
Output
1 0.25
2 0.0625
3 0.015625
4 0.00390625
5 0.0009765625
After 5 layers the error signal is about 1000 times smaller. That is why the early layers of deep sigmoid networks learn so slowly.
