Comments

Try each exercise yourself first. If you get stuck, open the hints one at a time, and only then look at the solution.

Quick recap from the lecture

  • A single-line comment starts with #. Python ignores everything after it on that line.
  • A comment can sit on its own line or at the end of a line of code.
  • Text between three quotes """ ... """ can span many lines. It is often used as a docstring: the description at the top of a function or module.

2.1Write code

Explain the code with comments

Add a comment above the program saying what it does, and a comment at the end of the qty line saying what qty means. The output must not change.
Starter code
price = 50
qty = 3
print(price * qty)
  1. Step 1. A comment starts with #.
  2. Step 2. For the first comment, add a new line at the very top that begins with #.
  3. Step 3. For the second, type two spaces and then # after qty = 3, then your note.
  4. Step 4. Run it: the output should still be just the number, because Python skips comments.
Show the full solution
Solution
# Calculate the total cost of an order
price = 50
qty = 3  # number of items bought
print(price * qty)
Expected output
150

2.3Write code
Write a docstring
Add a multiline docstring to this function explaining what it returns. The program should still print 12.
Starter code
def area(w, h):
    return w * h

print(area(3, 4))
  1. Step 1. A docstring goes on the first line inside the function, indented like the rest of the body.
  2. Step 2. Start it with """ and end it with """.
  3. Step 3. Write one or two short sentences: what the inputs are and what comes back.
Show the full solution
Solution
def area(w, h):
    """
    Return the area of a rectangle.
    w is the width and h is the height.
    """
    return w * h

print(area(3, 4))
Expected output
12

2.4Fix the bug
Fix the broken comment
This program crashes. Find the problem and fix it so it prints Hi.
Buggy code
This program prints a greeting
print("Hi")
  1. Step 1. Run it first and read the error: Python is trying to understand line 1 as code.
  2. Step 2. Line 1 is meant to be a note for humans, so Python must be told to skip it.
  3. Step 3. Put # at the start of line 1.
Show the full solution
Solution
# This program prints a greeting
print("Hi")
Expected output
Hi
Without #, Python reads This program prints... as code and stops with a SyntaxError.
