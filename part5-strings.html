Strings

Try each exercise yourself first. If you get stuck, open the hints one at a time, and only then look at the solution.

Quick recap from the lecture

  • There is no separate char type. Both '...' and "..." make strings, and + joins them.
  • Indexing starts at 0: s[0] is the first character. Negative indexes count from the end: s[-1] is the last character. An index that is too big raises an error.
  • Slicing s[start:stop:step] includes start but stops before stop. Leave either one out to go from the beginning or to the end. s[::-1] reverses.
  • Convert with str(), int() and float(). This is especially useful when you read numbers from a file or from input().
  • Use \' or \" to put a quote inside a string, or just pick the other kind of quote.
  • Useful methods: find, replace, startswith, isalpha, lower, upper, title, strip, split, join, format.

5.9Write code
Split and join a date
Turn '03-30-2016' into '03/30/2016' using split and join.
Starter code
date = '03-30-2016'
  1. Step 1. date.split(sep='-') (or simply date.split('-')) gives a list of the three parts.
  2. Step 2. join is called on the separator you want: '/'.join(parts).
  3. Step 3. Print the joined result.
Show the full solution
Solution
date = '03-30-2016'
parts = date.split(sep='-')
print(parts)
print('/'.join(parts))
Expected output
['03', '30', '2016']
03/30/2016

5.10Write code
Fill in the blanks with format
Use .format() to print Sam loves plums (with named placeholders) and 5 squared is 25 (with empty placeholders).
  1. Step 1. Curly braces {} in a string are placeholders.
  2. Step 2. Named version: "{name} loves {food}".format(name="Sam", food="plums").
  3. Step 3. Empty version: "{} squared is {}".format(5, 5 ** 2). Numbers are converted to text for you.
Show the full solution
Solution
print("{name} loves {food}".format(name="Sam", food="plums"))
print("{} squared is {}".format(5, 5 ** 2))
Expected output
Sam loves plums
5 squared is 25
