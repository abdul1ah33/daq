Practice workbook

83 hands-on exercises across the 9 parts of the lectures, plus a 63-question tracing quiz. Work through the parts in order, then test yourself with the quiz.

How each exercise works

  • Write code: build the program yourself. Predict the output: work out what is printed before running it. Fix the bug: find what is wrong and correct it.
  • Stuck? Press 💡 Show hint. Each press reveals the next small step, so you only see as much help as you need.
  • Show the full solution reveals the answer code and its exact output (every output was produced by actually running the code).
  • ▶ Try it in the editor runs real Python in your browser (internet needed the first time). You can also paste any code into Google Colab.
