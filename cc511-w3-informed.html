Week 3 · Informed (Heuristic) Search

Try each exercise yourself first. If you get stuck, open the hints one at a time, and only then look at the solution.

Quick recap from the lecture

  • Heuristic h(n) = estimated cost from n to the goal. It reduces the effective branching factor to 1 ≤ b* ≪ b.
  • Three ways to define f: value of the state (optimization), f = h(n), or f = g(n) + h(n).
  • 8-puzzle: h1 = misplaced tiles, h2 = sum of distances. h2 ≥ h1 → h2 is more informed and more efficient.
  • Admissible: h never overestimates. A* is optimal if h is admissible.
  • Greedy: f = h; not optimal, incomplete without repeated-state checks, O(bm). A*: f = g + h; complete, optimal, keeps all nodes (O(bd) space).

3.4Write code

Code h1 and h2 for the 8-puzzle

Boards are tuples read row by row, with 0 for the blank. Write h1 (misplaced tiles, ignoring the blank) and h2 (sum of row + column distances). Test them on the slide's boards.
Starter code
start = (7, 2, 4, 5, 0, 6, 8, 3, 1)
goal = (1, 2, 3, 4, 5, 6, 7, 8, 0)
  1. Step 1. h1: loop over positions with zip(state, goal); count when the tile isn't 0 and differs.
  2. Step 2. h2: for each tile v ≠ 0 at index i, find its goal index j = goal.index(v).
  3. Step 3. Row = index // 3 and column = index % 3. Add abs(row difference) + abs(column difference).
Show the full solution
Solution
start = (7, 2, 4, 5, 0, 6, 8, 3, 1)
goal = (1, 2, 3, 4, 5, 6, 7, 8, 0)

def h1(state, goal):
    count = 0
    for a, b in zip(state, goal):
        if a != 0 and a != b:
            count += 1
    return count

def h2(state, goal):
    total = 0
    for i, v in enumerate(state):
        if v == 0:
            continue
        j = goal.index(v)
        total += abs(i // 3 - j // 3) + abs(i % 3 - j % 3)
    return total

print("h1 =", h1(start, goal))
print("h2 =", h2(start, goal))
Expected output
h1 = 6
h2 = 14

3.5Write code
Greedy and A* in a few lines
Using the map and h table, write best_first(use_g): keep a frontier list of (f, node, g, path), always pop the smallest f. With use_g=False it's greedy, with True it's A*. Print the path and cost of each.
Starter code
graph = {"A": {"B": 75, "C": 118, "E": 140}, "B": {"A": 75}, "C": {"A": 118, "D": 111},
         "D": {"C": 111}, "E": {"A": 140, "G": 80, "F": 99}, "F": {"E": 99, "I": 211},
         "G": {"E": 80, "H": 97}, "H": {"G": 97, "I": 101}, "I": {"F": 211, "H": 101}}

  1. Step 1. Start: frontier = [(h["A"], "A", 0, ["A"])].
  2. Step 2. Loop: frontier.sort() then f, node, g, path = frontier.pop(0). If node is "I", return path and g.
  3. Step 3. For each neighbour m, cost in graph[node].items(): ng = g + cost, f = (ng if use_g else 0) + h[m]; append (f, m, ng, path + [m]).
Show the full solution
Solution
graph = {"A": {"B": 75, "C": 118, "E": 140}, "B": {"A": 75}, "C": {"A": 118, "D": 111},
         "D": {"C": 111}, "E": {"A": 140, "G": 80, "F": 99}, "F": {"E": 99, "I": 211},
         "G": {"E": 80, "H": 97}, "H": {"G": 97, "I": 101}, "I": {"F": 211, "H": 101}}
h = {"A": 366, "B": 374, "C": 329, "D": 244, "E": 253, "F": 178, "G": 193, "H": 98, "I": 0}

def best_first(use_g):
    frontier = [(h["A"], "A", 0, ["A"])]
    while frontier:
        frontier.sort()
        f, node, g, path = frontier.pop(0)
        if node == "I":
            return path, g
        for m, cost in graph[node].items():
            ng = g + cost
            f = (ng if use_g else 0) + h[m]
            frontier.append((f, m, ng, path + [m]))

print("greedy:", best_first(False))
print("A*:    ", best_first(True))
Expected output
greedy: (['A', 'E', 'F', 'I'], 450)
A*:     (['A', 'E', 'G', 'H', 'I'], 418)
The only difference between the two algorithms is whether g is added to f. That one change makes A* optimal.
